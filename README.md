NEON BREACH is a neon breakout roguelite: break the glowing brick wall across 8 sectors, draft 1 of 3 upgrades after each sector (multi-ball, laser paddle, fireball, guard floor and more), and beat the moving Sector Core boss in sector 8. Keyboard and mouse, synthesized sound, high score saved locally.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Space or click to start.
